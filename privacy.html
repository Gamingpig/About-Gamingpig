Gamingpig
E-Mail: gamingpig.support@gmail.com

2. Welche Daten werden erhoben?

Die Website hat keine eigene Benutzerverwaltung, kein Analytics-Tracking und keine Werbung. Für das freiwillige Voting und das Einreichen von Wünschen wird jedoch ein GitHub-Konto genutzt. Die dabei verarbeiteten personenbezogenen und öffentlichen Daten werden in Abschnitt 14 erklärt. Daneben erhalten die unten genannten externen Dienste technische Verbindungsdaten.

  • Es werden keine Standortdaten erhoben.
  • Es werden keine Kontakte, Fotos oder Dateien ausgelesen.
  • Es findet keine Analyse des Nutzerverhaltens (Analytics) statt.

3. Hosting & technische Zugriffsdaten

Die Inhalte werden über GitHub Pages (GitHub Inc., bzw. GitHub B.V. in der EU) ausgeliefert. Wie bei jedem Webseitenaufruf verarbeitet GitHub dabei automatisch technische Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt des Zugriffs, User-Agent) im Rahmen des normalen Serverbetriebs. Diese Verarbeitung liegt außerhalb meines Einflusses; weitere Informationen dazu bietet die Datenschutzerklärung von GitHub.

4. Berechtigungen der App

Die App benötigt lediglich eine bestehende Internetverbindung, um die Website-Inhalte anzuzeigen. Es werden keine weiteren Geräteberechtigungen (Kamera, Mikrofon, Kontakte, Standort etc.) angefordert.

5. Externe Schriftarten

Zur einheitlichen Darstellung lädt die Website die Schriftarten „Inter“ und „JetBrains Mono“ über Google Fonts. Dabei stellt dein Browser eine Verbindung zu Servern von Google her. Hierbei werden technisch bedingt insbesondere deine IP-Adresse, Browserinformationen sowie Zeitpunkt und angeforderte Datei an Google übermittelt.

6. Musik-Dashboard, Stats.fm Wrapped und externe Dienste

Das Musik-Dashboard ruft aktuelle Titelinformationen über die API von npc-api.aikins.xyz ab. Für Songtexte werden LRCLIB und ersatzweise eine auf Vercel bereitgestellte Schnittstelle für NetEase Cloud Music kontaktiert. Zur zuverlässigen Anzeige hochauflösender Album-Covers wird eine mehrstufige Abfragekette genutzt: Zunächst wird bei vorhandener Apple Music ID die Apple iTunes Lookup API angefragt, gefolgt vom offiziellen Spotify oEmbed-Dienst (open.spotify.com/oembed), der Apple iTunes Search API sowie einer JSONP-Suchanfrage an Deezer, bevor als letzte Stufe ein lokales Platzhalterbild angezeigt wird. Für die Spotify Wrapped / Musik-Statistiken werden ausschließlich öffentliche Aggregationsdaten des Profils gamingpig über die offizielle API von stats.fm (api.stats.fm) abgerufen. Dabei werden zu keinem Zeitpunkt persönliche Daten der Besucher an stats.fm oder Spotify übermittelt. Wie bei jedem direkten Internetaufruf erhalten die jeweiligen Schnittstellenanbieter lediglich technisch unvermeidbare Verbindungsdaten (z. B. IP-Adresse und User-Agent).

Externe Inhalte werden erst verarbeitet, wenn die jeweilige Funktion geladen oder verwendet wird. Für die Verarbeitung durch die Drittanbieter gelten deren eigene Datenschutzbestimmungen; auf deren Speicherdauer und weitere Verarbeitung habe ich keinen Einfluss.

7. Sprachausgabe (Vorlesen-Funktion)

Die Website bietet an vielen Stellen eine optionale Vorlesen-Funktion an, die nur bei aktivem Klick auf den entsprechenden Button startet. Diese Funktion nutzt die im Browser eingebaute Sprachausgabe (Web Speech API). Je nach Browser und Betriebssystem kann die Sprachverarbeitung entweder vollständig lokal auf deinem Gerät stattfinden, oder der Browser sendet den vorzulesenden Text zur Verarbeitung an einen Cloud-Dienst des jeweiligen Anbieters (z. B. Google bei Chrome-Systemstimmen). Ich habe darauf keinen Einfluss - welche Stimmen lokal oder über die Cloud laufen, entscheidet dein Browser bzw. Betriebssystem. Beim synchronisierten Vorlesen von Songtexten wird die Textsprache automatisch auf deinem Endgerät analysiert, um eine passende Sprachausgabe-Stimme zu wählen. Zudem kann die Vorlesegeschwindigkeit individuell reguliert werden. Es werden dabei ausschließlich die sichtbaren Seiteninhalte (z. B. Songtexte, Bio, Karteninhalte) vorgelesen, keine persönlichen oder eingegebenen Nutzerdaten.

8. Discord-Widget im Support-Bereich

Im Support-Bereich der Website wird die aktuelle Mitglieder- und Online-Zahl meines Discord-Servers live angezeigt. Dafür ruft dein Browser beim Laden der Seite automatisch die öffentliche Einladungs-API von discord.com auf. Dabei werden die üblichen technischen Verbindungsdaten (IP-Adresse, Zeitpunkt, Browserinformationen) an Discord Inc. übermittelt. Es werden keine Nutzerkonten oder sonstigen persönlichen Daten von dir an Discord übertragen. Weitere Informationen bietet die Datenschutzerklärung von Discord.

9. Lokale Speicherung im Browser (localStorage)

Sprache, Design, Vorlesestimme und -tempo, der lokale Songverlauf sowie Einführungs- und Datenschutz-Versionsstände werden im Browser gespeichert. Der Roadmap-Lesecache (gp_github_roadmap_v1:Gamingpig/About-Gamingpig) enthält zuletzt geladene öffentliche Stimmzahlen und bis zu 30 Wünsche einschließlich GitHub-Nutzername, Text, Datum und Status. Er wird bei erfolgreicher Synchronisierung ersetzt, hat aber keine automatische Ablaufzeit. Alte, noch nicht abgesendete lokale Wünsche können zur Wiederherstellung vorhanden sein. Diese Speicher werden nicht als Nutzerprofil hochgeladen. Über die Browsereinstellungen kannst du sie löschen; dadurch werden keine GitHub-Issues oder Reaktionen gelöscht.

10. Web-Push-Benachrichtigungen & Störungs-Überwachung

Die Website und PWA bietet eine freiwillige Störungs-Benachrichtigung (Web Push) an. Die Aktivierung erfolgt rein opt-in-basiert über deine ausdrückliche Zustimmung (Art. 6 Abs. 1 lit. a DSGVO). Zur technischen Zustellung von Meldungen bei API-Ausfällen generiert dein Browser einen pseudonymisierten Push-Endpunkt (z. B. über Google Firebase Cloud Messaging oder Apple Web Push). Es werden keine Namen, E-Mail-Adressen oder Geräteprofile verknüpft. Du kannst die Benachrichtigungen jederzeit mit einem Klick auf der Status-Seite oder in den Browsereinstellungen wieder deaktivieren.

Diese Datenschutzerklärung kann bei Bedarf aktualisiert werden, z. B. wenn neue Funktionen hinzukommen. Die jeweils aktuelle Version ist immer auf dieser Seite verfügbar.

Privacy Policy

Gamingpig Portfolio · Last updated: September 8, 2026

2. What data is collected?

The website has no account system of its own, analytics tracking or advertising. Optional voting and wish submissions use a GitHub account and process personal and public data as described in section 14. External services listed below also receive technical connection data.

  • No location data is collected.
  • No contacts, photos, or files are read.
  • No analysis of user behavior (analytics) takes place.

3. Hosting & technical access data

The content is delivered via GitHub Pages (GitHub Inc., or GitHub B.V. in the EU). The app only requires an existing internet connection to display the website content. No further device permissions (camera, microphone, contacts, location, etc.) are requested.

For consistent display, the website loads the fonts "Inter" and "JetBrains Mono" via Google Fonts. Your browser thereby establishes a connection to Google's servers. This technically transmits your IP address, browser information, and the time and requested file to Google.

6. Music Dashboard, Stats.fm Wrapped and External Services

The music dashboard retrieves current track information via the API of npc-api.aikins.xyz. For lyrics, LRCLIB is contacted, and alternatively a Vercel-hosted interface for NetEase Cloud Music. To reliably display high-resolution album artwork, a multi-stage sequential query chain is used: First, if an Apple Music ID is present, the Apple iTunes Lookup API is queried, followed by the official Spotify oEmbed service (open.spotify.com/oembed), Apple's iTunes Search API, and a JSONP search request to Deezer, before a local placeholder image is shown as a final fallback. For the Spotify Wrapped / Music Statistics, only public aggregation data of the profile gamingpig is retrieved via the official API of stats.fm (api.stats.fm). At no time are personal data of visitors transmitted to stats.fm or Spotify. As with any direct internet request, the respective providers only receive technically necessary connection data (e.g. IP address and user agent).

External content is only processed once the respective feature is loaded or used. Processing by third-party providers is subject to their own privacy policies; I have no influence over their retention periods or further processing.

7. Voice narration (read-aloud feature)

The website offers an optional read-aloud feature in many places, which only starts when the corresponding button is actively clicked. This feature uses the browser's built-in voice synthesis (Web Speech API). Depending on the browser and operating system, speech processing may take place entirely locally on your device, or the browser may send the text to be read aloud to a cloud service of the respective provider for processing (e.g. Google for Chrome system voices). I have no influence over this - which voices run locally or via the cloud is determined by your browser or operating system. Only the visible page content (e.g. lyrics, description text) is read aloud, no personal or entered data.

8. Discord widget in the support section

In the support section of the website, the current member and online count of my Discord server is displayed live. To do this, your browser automatically calls the public invite API of discord.com when the page loads. This transmits the usual technical connection data (IP address, time, browser information) to Discord Inc. No user accounts or other personal data are transmitted from you to Discord. Further information is available in the Discord Privacy Policy.

9. Local storage in the browser (localStorage)

Language, design, speech voice and speed, recent songs, onboarding and privacy version flags are stored in the browser. The roadmap read cache (gp_github_roadmap_v1:Gamingpig/About-Gamingpig) holds the last public vote counts and up to 30 wishes including GitHub username, text, date and status. Successful synchronization replaces it; it has no automatic expiry. Old unsubmitted local wishes may remain available for recovery. These stores are not uploaded as a user profile. Clearing website data in your browser removes them, but does not delete GitHub issues or reactions.

10. Web Push Notifications & Outage Alerts

The website and PWA offer optional outage and incident alerts (Web Push). Activation is strictly opt-in based on your explicit consent (Art. 6(1)(a) GDPR). For message delivery when services go down, your browser generates a pseudonymized push endpoint (via Google FCM or Apple Push Services). No personal names, emails, or device tracking profiles are linked. You can revoke and disable notifications at any time directly on the status page or via your browser settings.

The purpose is shared feature planning and displaying votes and ideas across devices. Data is stored in the public Gamingpig/About-Gamingpig GitHub repository. Reading requires no login; voting and submitting require a GitHub account. The website receives neither your GitHub password nor a private access token.

Wishes are issues: your GitHub username, entered name/Discord tag, category, title, description and publication date are public. A pseudonym is sufficient; do not enter confidential information or other people’s data. Clicking “Submit on GitHub” already transfers the form text to GitHub through a prefilled URL, which may remain in browser history. Confirming on GitHub publishes the issue. Votes are public 👍 reactions on the first feature post, linked to your GitHub account there. The website displays totals and the latest 30 wishes.
