Das Musik-Dashboard ruft aktuelle Titelinformationen über die API von npc-api.aikins.xyz ab. Für Songtexte werden LRCLIB und ersatzweise eine auf Vercel bereitgestellte Schnittstelle für NetEase Cloud Music kontaktiert. Zur zuverlässigen Anzeige hochauflösender Album-Covers wird eine mehrstufige Abfragekette genutzt: Zunächst wird bei vorhandener Apple Music ID die Apple iTunes Lookup API angefragt, gefolgt vom offiziellen Spotify oEmbed-Dienst (open.spotify.com/oembed), der Apple iTunes Search API sowie einer JSONP-Suchanfrage an Deezer, bevor als letzte Stufe ein lokales Platzhalterbild angezeigt wird. Für die Spotify Wrapped / Musik-Statistiken werden ausschließlich öffentliche Aggregationsdaten des Profils gamingpig über die offizielle API von stats.fm (api.stats.fm) abgerufen. Dabei werden zu keinem Zeitpunkt persönliche Daten der Besucher an stats.fm oder Spotify übermittelt. Wie bei jedem direkten Internetaufruf erhalten die jeweiligen Schnittstellenanbieter lediglich technisch unvermeidbare Verbindungsdaten (z. B. IP-Adresse und User-Agent).

Externe Inhalte werden erst verarbeitet, wenn die jeweilige Funktion geladen oder verwendet wird. Für die Verarbeitung durch die Drittanbieter gelten deren eigene Datenschutzbestimmungen; auf deren Speicherdauer und weitere Verarbeitung habe ich keinen Einfluss.

Je nach Browser und Betriebssystem kann die Sprachverarbeitung entweder vollständig lokal auf deinem Gerät stattfinden, oder der Browser sendet den vorzulesenden Text zur Verarbeitung an einen Cloud-Dienst des jeweiligen Anbieters (z. Zudem kann die Vorlesegeschwindigkeit individuell reguliert werden. Es werden dabei ausschließlich die sichtbaren Seiteninhalte (z. B. The music dashboard retrieves current track information via the API of npc-api.aikins.xyz. For lyrics, LRCLIB is contacted, and alternatively a Vercel-hosted interface for NetEase Cloud Music. To reliably display high-resolution album artwork, a multi-stage sequential query chain is used: First, if an Apple Music ID is present, the Apple iTunes Lookup API is queried, followed by the official Spotify oEmbed service (open.spotify.com/oembed), Apple's iTunes Search API, and a JSONP search request to Deezer, before a local placeholder image is shown as a final fallback. For the Spotify Wrapped / Music Statistics, only public aggregation data of the profile gamingpig is retrieved via the official API of stats.fm (api.stats.fm). At no time are personal data of visitors transmitted to stats.fm or Spotify. As with any direct internet request, the respective providers only receive technically necessary connection data (e.g. IP address and user agent).

External content is only processed once the respective feature is loaded or used. Processing by third-party providers is subject to their own privacy policies; I have no influence over their retention periods or further processing.

7. Voice narration (read-aloud feature)

The website offers an optional read-aloud feature in many places, which only starts when the corresponding button is actively clicked. This feature uses the browser's built-in voice synthesis (Web Speech API). Depending on the browser and operating system, speech processing may take place entirely locally on your device, or the browser may send the text to be read aloud to a cloud service of the respective provider for processing (e.g. Google for Chrome system voices). I have no influence over this - which voices run locally or via the cloud is determined by your browser or operating system. Only the visible page content (e.g. lyrics, description text) is read aloud, no personal or entered data.

8. Discord widget in the support section

In the support section of the website, the current member and online count of my Discord server is displayed live. To do this, your browser automatically calls the public invite API of discord.com when the page loads. This transmits the usual technical connection data (IP address, time, browser information) to Discord Inc. No user accounts or other personal data are transmitted from you to Discord. Further information is available in the Discord Privacy Policy.

9. Local storage in the browser (localStorage)

The website stores certain settings and history data exclusively locally in your browser (localStorage) - this data never leaves your device and is never transmitted to anyone. This includes, for example: selected language, design settings (e.g. light/dark mode, activated effects), whether the introductory tutorial has already been seen, the most recently selected read-aloud voice, and a brief history of the most recently played songs ("Recently played"). You can remove this data yourself at any time via your browser settings (clear website data).

10. Web Push Notifications & Outage Alerts

The website and PWA offer optional outage and incident alerts (Web Push). Activation is strictly opt-in based on your explicit consent (Art. 6(1)(a) GDPR). For message delivery when services go down, your browser generates a pseudonymized push endpoint (via Google FCM or Apple Push Services). Para uma exibição uniforme, o site carrega as fontes "Inter" e "JetBrains Mono" via Google Fonts. Com isso, seu navegador estabelece uma conexão com os servidores do Google. Isso transmite tecnicamente seu endereço IP, informações do navegador, além do momento e do arquivo solicitado, ao Google.

6. Painel de música, Stats.fm Wrapped e serviços externos

O painel de música obtém informações da faixa atual via a API de npc-api.aikins.xyz. Para as letras, o LRCLIB é contatado, e alternativamente uma interface hospedada na Vercel para o NetEase Cloud Music. Para garantir a exibição confiável de capas de álbum em alta definição, uma cadeia de busca sequencial é utilizada: primeiro, se houver um Apple Music ID, consulta-se a Apple iTunes Lookup API, seguida pelo serviço oficial Spotify oEmbed (open.spotify.com/oembed), a Apple iTunes Search API e uma busca JSONP no Deezer, antes de exibir uma imagem de espaço reservado local como último recurso. Para o Spotify Wrapped / Estatísticas de Música, apenas dados de agregação públicos do perfil gamingpig são obtidos através da API oficial do stats.fm (api.stats.fm). Em nenhum momento dados pessoais dos visitantes são transmitidos ao stats.fm ou ao Spotify. Como em qualquer requisição direta à internet, os respectivos provedores recebem apenas dados de conexão tecnicamente necessários (ex.: endereço IP e user agent).

Conteúdo externo só é processado quando a respectiva função é carregada ou usada. O processamento por provedores terceiros está sujeito às suas próprias políticas de privacidade; não tenho influência sobre o período de retenção ou o processamento posterior por parte deles.

7. Narração por voz (função de leitura em voz alta)

O site oferece em muitos lugares uma função opcional de leitura em voz alta, que só inicia ao clicar ativamente no botão correspondente. Essa função usa a síntese de voz embutida no navegador (Web Speech API). Dependendo do navegador e sistema operacional, o processamento de voz pode ocorrer inteiramente local no seu dispositivo, ou o navegador pode enviar o texto a ser lido para um serviço em nuvem do respectivo provedor para processamento (ex.: Google no caso das vozes do sistema do Chrome). Não tenho influência sobre isso - quais vozes rodam localmente ou pela nuvem é decidido pelo seu navegador ou sistema operacional. Apenas o conteúdo visível da página (ex.: letra da música, textos descritivos) é lido em voz alta, nenhum dado pessoal ou inserido.

Para isso, seu navegador chama automaticamente a API pública de convite de discord.com ao carregar a página. Isso transmite os dados técnicos de conexão usuais (endereço IP, momento, informações do navegador) para a Discord Inc. Nenhuma conta de usuário ou outro dado pessoal seu é transmitido ao Discord.
